# Poorna S K — Portfolio

A responsive, multi-page portfolio starter built with semantic HTML, CSS, and a small amount of JavaScript.

## Open it

Open `index.html` in a browser. The four pages link to one another and do not require a build step.

## Personalize before submitting

- Update the bio, skills, projects, and location in `about.html`, `projects.html`, and `index.html` so they accurately describe you.
- Add your email address to the `mailto:` link in `script.js` (currently the form opens a draft with the recipient blank).
- Replace the project placeholders with real work and links when available.
- Add a real domain to canonical metadata after publishing the site.

The contact form validates its required fields and opens an email draft in the visitor's mail app. It does not send or store messages by itself; a live form needs a backend or form service.
